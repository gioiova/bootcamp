# Simple Product Store

### A simple product store application built using FakeStoreAPI. This app displays a list of products and provides a detailed page for each product. It utilizes getServerSideProps for data fetching and Next.js pages router for navigation.

## Features

Displays a list of products from FakeStoreAPI

Product detail page with more information

Server-side rendering using getServerSideProps

Page-based routing with Next.js
